# UXSPSdk (Swift)

Universal Exchange Security Protocol Swift iOS / macOS Client SDK.

## Installation (Swift Package Manager)

Add `https://github.com/SIVA-RAJA/uxsp.git` in Xcode or `Package.swift`:

```swift
.package(url: "https://github.com/SIVA-RAJA/uxsp.git", from: "1.2.0")
```
